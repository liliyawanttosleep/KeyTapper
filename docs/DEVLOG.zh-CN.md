## 1. 项目是什么

Windows 上的键盘连点器。单文件 Python 程序（`keytapper.py`），界面用 tkinter，
按键通过 Win32 `SendInput` 发送到前台窗口。唯一的第三方依赖是 Pillow。

## 2. 目前已实现的功能

| 类别 | 功能 |
| --- | --- |
| 按键 | 单键、组合键（Ctrl / Shift / Alt / Win + 任意键）、仅修饰键、鼠标左 / 右 / 中键 |
| 序列 | 多步循环（A → B → C → 回到 A）；每步可设连按次数（1–999）和单独的等待时间 |
| 时间 | 默认间隔（毫秒 / 秒 / 分钟，最小 1 毫秒）、开始延迟、按住时长、随机浮动 |
| 停止 | 手动、持续指定时长、循环指定轮数 |
| 热键 | 全局启停热键，默认 F6，可改为任意键或组合键 |
| 游戏兼容 | 启动时自动申请管理员权限；发送方式可选「游戏兼容」（扫描码）或「普通」（虚拟键码） |
| 方案 | 命名方案的保存 / 另存为 / 删除 / 切换；导出为 `.json`，导入他人的方案 |
| 反馈 | 状态胶囊、按键次数 / 完成轮数 / 运行时间面板、进度条、开始与停止提示音 |
| 其他 | 窗口置顶、记住窗口位置、防重复启动、设置自动保存、出错写入 `error.log` |

## 3. 开发历程

### v0.1 — 基础连点器（2026-11-12）
- 用 tkinter + ctypes 写出第一版，浅色界面，纯标准库。
- 核心模型从一开始就是「步骤列表」：只有一步就是普通连点，多步就是循环。
- 录制按键用轮询 `GetAsyncKeyState` 实现，而不是 Tk 的键盘事件。
  原因：中文输入法开启时 Tk 收到的键码是 229（VK_PROCESSKEY），读不到真实按键。
- 全局热键同样用轮询实现（25 毫秒一次），没有用 `RegisterHotKey` 或键盘钩子。

### v0.2 — 游戏内生效、方案系统（2026-11-12）
- **问题**：用户反馈在游戏里不生效，热键也停不下来，游戏外一切正常。
- **原因**：游戏以管理员身份运行。Windows 的 UIPI 会拦截低权限进程发给高权限窗口的输入，
  同时低权限进程的 `GetAsyncKeyState` 也读不到用户在高权限窗口里的按键。
- **修复**：启动时用 `ShellExecuteW(..., "runas", ...)` 自提权；被拒绝则以普通权限继续并在界面上警告。
- 发送方式改为默认使用 `KEYEVENTF_SCANCODE`，保留「普通」模式作为备选。
- 新增方案：保存、切换、导入、导出；导入内容经过 `sanitize_preset` 校验。
- 用户确认此版本在其游戏中可以正常工作。

### v0.3 — 新界面、图标、功能补充（2026-11-12）
- 界面改为深色主题。圆角卡片、按钮、输入框都是 Pillow 画出来的贴图，
  通过 ttk 的 image element 做九宫格拉伸。
- 新图标：键帽上的无限循环符号 + 敲击波纹，由 `tools/make_icon.py` 生成。
- 新增：每步连按次数、复制步骤、提示音、数据面板、进度条、防重复启动、记住窗口位置。
- 提示 / 确认 / 输入弹窗改为自绘（`MsgDialog`），只有文件选择框仍是系统自带的。

### v0.3 发布（2026-11-12）
- 整理为 GitHub 仓库：README、MIT 许可证、依赖清单、示例方案、快捷方式脚本。
- 加入 `tests/selftest.py` 和本开发日志。

## 4. 代码结构

全部逻辑在 `keytapper.py`，按注释分节，从上到下：

| 小节 | 内容 |
| --- | --- |
| 系统按键发送 | ctypes 结构体、`KEY_NAMES`、`combo_text`、`is_down`、`send_key` |
| 连点引擎 | `Tapper`：后台线程，按 job 循环发送按键，用 `perf_counter` 做精确等待 |
| 配置 | `DEFAULT_CFG`、`PRESET_KEYS`、`sanitize_preset`、`load_cfg`、`ensure_admin` |
| 配色与绘图 | 颜色常量、`dark_titlebar`、`Gfx`（画贴图）、`BigButton`（渐变主按钮） |
| 对话框 | `Dialog` 基类、`MsgDialog`、`StepDialog`（录制按键） |
| 主窗口 | `App`：样式、布局、序列编辑、方案、启停、`_tick` 定时刷新 |
| 入口 | `already_running`（互斥量）、`main` |

### 数据流

```
界面上的输入 ──_collect()──> self.cfg ──build_job()──> job ──> Tapper.start(job)
                                 │
                                 └──_save()──> config.json
```

- `cfg["steps"]` 里的一步：`{"mods": [17, 16], "key": 65, "times": 1, "interval": null, "unit": "毫秒"}`
  - `mods` / `key` 是 Windows 虚拟键码；鼠标键用 1 / 2 / 4。
  - `interval` 为 `null` 表示使用默认间隔。
- `build_job()` 把步骤展开成引擎用的扁平列表（连按次数在这里展开），每项是
  `{"mods": [...], "key": vk, "gap_ms": 毫秒}`。「一轮」指展开后的列表完整执行一遍。
- 导出文件格式：`{"app": "KeyTapper", "version": 1, "name": "...", "preset": {PRESET_KEYS 对应的字段}}`。
  示例见 `examples/abc-loop.json`。
- 热键、置顶、提示音、发送方式、窗口位置属于本机设置，不随方案导出。

## 5. 已经踩过的坑（改代码前请先读）

1. **ttk 图片元素必须写 `padding=0`**。否则元素会把 `border` 当作内边距，所有控件都会胖一圈。
2. **按钮样式必须写 `width=0`**。clam 主题给 TButton 的默认最小宽度是 11 个字符。
3. **贴图不带透明通道**，圆角外侧是预先填好的父容器背景色。
   所以把控件放到不同底色的容器里时，要用对应底色重新生成贴图（见 `nine()` 的 `bg` 参数）。
4. **所有尺寸都要过 `self.S()` 或 `Gfx.px()`**。程序开启了 DPI 感知，写死像素值在高分屏上会变小。
5. **`element_create` 的名字在一个 Tk 解释器里只能创建一次**，所以一个进程里只能有一个 `App`。
6. **运行中会禁用所有输入控件，并把焦点移到根窗口**。
   否则当连点器自己是前台窗口时，发送出去的按键会打进输入框或触发按钮。
7. **启停热键不能和序列里的按键相同**，否则发送出去的按键会被热键轮询读到，自己把自己停掉。
   `start()` 里有检查。
8. **新增配置项时**：加到 `DEFAULT_CFG`；属于方案的再加到 `PRESET_KEYS`，并在 `sanitize_preset`、
   `_collect`、`_apply_preset` 里处理。旧的 `config.json` 缺字段时会自动用默认值。
9. **写 `.bat` 和 `.ps1` 时只用 ASCII 字符**，否则在中文 Windows 的默认编码下会乱码。

## 6. 如何验证

```bash
pip install -r requirements.txt
python tests/selftest.py
```

自检会：用 F13 / F14 / F15 这三个一般没有绑定功能的键跑引擎（两种发送方式、限时、限轮数、倒计时中停止），
检查方案的导出 / 导入 / 非法文件拒绝，然后打开真实窗口跑一遍带轮数限制的连点。
它使用临时目录里的配置，不会读写你的 `config.json`，也不需要管理员权限。
注意它会向系统发送真实的按键事件，运行期间窗口会短暂弹出。

自检覆盖不到、需要人工确认的部分：管理员提权流程、录制按键、F6 热键、在真实游戏中的效果。

## 7. 已知限制

- 还没有打包成独立的 exe，使用者需要自己安装 Python 和 Pillow。
- 带内核级反作弊的游戏会屏蔽 `SendInput`，这在用户态无法解决。
- 不区分左右修饰键（左 Shift / 右 Shift），也不区分主键盘 Enter 和小键盘 Enter。
- 鼠标键只能在当前光标位置点击，不能指定坐标。
- 界面只有中文。
- 导入 / 导出使用系统自带的文件对话框，是浅色的，和主题不一致。
- 间隔低于约 10 毫秒时，实际速率受 `按住时长` 和系统调度限制。

1. 用 PyInstaller 打包成 exe，并在清单里声明 `requireAdministrator`，在 GitHub Releases 发布。
2. 界面多语言（至少加英文），把界面字符串集中到一张表里。
3. 鼠标点击指定坐标、鼠标移动。
4. 录制一段真实操作并回放（宏）。
5. 只在指定窗口处于前台时才发送按键。
6. 开始和停止使用不同的热键；「按住热键时连点」模式。
7. 最小化到系统托盘。
8. 把 `keytapper.py` 拆成 `engine` / `config` / `ui` 几个模块，并为引擎和配置补单元测试。
